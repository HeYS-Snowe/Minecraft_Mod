# 功能需求 - CriticalCore

## 概述

临界核心 (CriticalCore) 是斩杀线 (Kill_line) 的可选前置 mod。安装后，斩杀线附魔无法从附魔台获取，必须通过复杂的合成链（临界工坊→渗透祭坛→诫命之砧）获得。未安装时，Kill_line 保持 V1.x 行为。

## 世界观

古代建造者文明发现了"阈界晶簇"，能感知代码层的"临界状态"。他们建造了脉冲锻炉来提取临界核心。文明灭亡后，玩家重新寻获这些遗物，继承建造者的遗愿。

## 物品

| 名称   | 注册名                       | 类型   | 获取方式       | 功能                 |
| ---- | ------------------------- | ---- | ---------- | ------------------ |
| 阈界碎片 | `threshold_shard`         | Item | 挖掘阈界晶簇    | 脉冲锻炉原料             |
| 临界核心 | `critical_core`           | Item | 脉冲锻炉合成    | 持有激活阈值感知；Kill_line合成链核心材料 |
| 临界手札 | `critical_handbook`       | Item | 创造模式       | 引导道具               |
| 虚空瓶  | `void_bottle`             | Item | 工作台合成      | 收集龙息残渣（Kill_line用） |
| 稳定核心 | `stable_core`             | Item | 工作台合成      | 渗透祭坛保险，100%合成成功    |

## 方块

| 名称   | 注册名                         | 类型   | 功能                    |
| ---- | --------------------------- | ---- | --------------------- |
| 阈界晶簇 | `threshold_crystal_cluster` | 矿石   | 生成于 Y=-64~-30，掉落阈界碎片  |
| 脉冲锻炉 | `pulse_forge`               | 工作台  | 阈界碎片×8 + 经验 → 临界核心×1  |

## 矿石生成

| 参数   | 默认值        | 可配置 |
| ---- | ---------- | --- |
| Y 范围 | -64 ~ -30  | ✓   |
| 每区块脉数 | 2          | ✓   |
| 每脉方块数 | 5          | —   |

## 阈值感知

- 持有临界核心时激活被动能力
- 检测范围 16 格内生命值 < 20% 的生物
- 屏幕边缘紫色脉冲光提示
- 参数可配置

## 对外 API

```java
CriticalCoreAPI.isLoaded()             // 是否安装
CriticalCoreAPI.getCriticalCoreItem()  // 获取临界核心物品
CriticalCoreAPI.getStableCoreItem()    // 获取稳定核心物品
```

## 配置文件 (`config/critical_core.toml`)

| 配置组   | 参数                   | 默认值  |
| ------ | -------------------- | ---- |
| 矿石生成  | orePerChunk          | 2    |
| 矿石生成  | minY / maxY          | -64/-30 |
| 脉冲锻炉  | experienceCost       | 5    |
| 脉冲锻炉  | craftingTimeTicks     | 100  |
| 脉冲锻炉  | shardsRequired       | 8    |
| 阈值感知  | detectionRange       | 16.0 |
| 阈值感知  | healthThreshold      | 0.20 |
