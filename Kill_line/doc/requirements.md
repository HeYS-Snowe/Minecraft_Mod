# 功能需求 - Kill_line

## 概述

斩杀线 (Kill Line) 附魔 Mod。为武器添加"斩杀线"附魔，攻击时标记目标，当目标血量低于阈值时有概率直接击杀。V2.0 增加可选前置 mod CriticalCore，安装后需通过合成链获取附魔。

## 附魔属性

| 属性      | 值                    |
| ------- | -------------------- |
| 名称      | 斩杀线 (Kill Line)      |
| 最高等级    | 5                    |
| 适用物品    | 武器                   |
| 附魔权重    | 2（稀有）                |

## 核心机制

### 斩杀阈值

| 等级  | 阈值  | 斩杀概率 |
| --- | --- | ---- |
| 1   | 20% | 20%  |
| 2   | 25% | 40%  |
| 3   | 30% | 60%  |
| 4   | 35% | 80%  |
| 5   | 40% | 100% |

公式：阈值 = 20% + (level - 1) * 5%，斩杀概率 = level * 20%

### 标记系统

- 攻击者使用带斩杀线附魔的武器攻击目标时施加标记
- 标记绑定攻击者，同一目标被不同攻击者攻击时标记会覆盖
- 目标死亡时自动清除标记
- 每次攻击在已标记且血量低于阈值时进行斩杀判定

### 无敌击杀

- 对创造模式玩家、高版本嘎吱怪等不可攻击实体，通过"斩杀线追踪"机制击杀
- 客户端追踪鼠标划过实体的轨迹，完成后发送斩杀请求

## V2.0 新增：合成链系统（需安装 CriticalCore）

当 CriticalCore 已安装时，斩杀线附魔变为 treasure-only，只能通过以下合成链获取。

### 合成流程

```
阶段1: 获取引导
  临界手札 → 右键阅读

阶段2: 合成临界工坊
  远古今石×4 + 虚空框架×1 + 血月核心×1 → 临界工坊方块

阶段3: 提纯临界精粹
  临界核心 + 寂灭尘埃×6 + 命运丝线×2 + 古神残页×1 → 临界工坊 → 临界精粹

阶段4: 合成临界卷轴（渗透祭坛，有失败风险）
  临界精粹 + 古神残页×2 + 命运丝线×1 → 渗透祭坛 → 临界卷轴
  成功率 90%（可配置），失败时祭坛破碎，材料随机返还 60%-90%
  稳定核心放入保险槽 = 100% 成功

阶段5: 诫命之砧附魔
  武器 + 临界卷轴 + 灵魂火花×1 → 诫命之砧 → 斩杀线附魔武器
  成功率 85%（可配置），失败仅消耗卷轴
```

| 参数                  | NORMAL | HARD | EXTREME |
| ------------------- | ------ | ---- | ------- |
| 卷轴合成成功率             | 90%    | 70%  | 50%     |
| 附魔成功率               | 85%    | 65%  | 40%     |
| 材料返还下限              | 60%    | 40%  | 20%     |

| 每区块矿石               | 2      | 1    | 0       |

## 视觉效果

- 标记粒子：被标记实体头顶紫色附魔粒子
- 阈值粒子：达到斩杀阈值时旋转紫色粒子环
- 裂纹血条：准星下方目标裂纹血条 HUD
- 斩杀特效：伤害粒子 + 爆炸粒子 + 横扫粒子 + 暴击音效
- 7种死亡动画：横斩、纵裂、断首、穿刺、升天、冰碎、灰化
