# 功能需求 - Kill_line

## 概述

斩杀线附魔 Mod。为剑添加"斩杀线"附魔，攻击时标记目标，当目标血量低于阈值时有概率直接击杀。

## 附魔属性

| 属性      | 值                    |
| ------- | -------------------- |
| 名称      | 斩杀线 (Kill Line)      |
| 最高等级    | 5                    |
| 适用物品    | 剑                    |
| 附魔权重    | 2（稀有）                |
| 附魔台等级需求 | 1-69                 |
| 铁砧消耗    | 4                    |
| 附魔互斥    | 无（可与锋利、亡灵杀手、节肢杀手等共存） |

## 核心机制

### 斩杀阈值

目标当前血量百分比低于阈值时进入斩杀判定：

| 等级  | 阈值  | 斩杀概率 |
| --- | --- | ---- |
| 1   | 20% | 20%  |
| 2   | 25% | 40%  |
| 3   | 30% | 60%  |
| 4   | 35% | 80%  |
| 5   | 40% | 100% |

公式：阈值 = 20% + (level - 1) * 5%，斩杀概率 = level * 20%

### 标记系统

- 攻击者使用带斩杀线附魔的武器攻击目标时，为目标施加标记
- 标记绑定攻击者，同一目标被不同攻击者攻击时标记会覆盖
- 目标死亡时自动清除标记
- 每次攻击在已标记且血量低于阈值时进行斩杀判定

### 可见性规则

| 场景      | 标记/阈值可见 | 斩杀特效可见 |
| ------- | ------- | ------ |
| 玩家 → 生物 | 所有附近玩家  | 所有附近玩家 |
| 玩家 → 玩家 | 仅攻击者    | 所有附近玩家 |
| 生物 → 玩家 | 所有附近玩家  | 所有附近玩家 |

## 视觉效果

- **标记粒子**：被标记实体头顶显示紫色附魔粒子（每 4 tick 一次）
- **阈值粒子**：达到斩杀阈值时，实体头顶显示旋转的紫色粒子环
- **裂纹血条**：准星下方显示目标的裂纹血条 HUD（需准星对准目标）
- **斩杀特效**：击杀成功时产生伤害粒子、爆炸粒子、横扫粒子 + 暴击音效

## 设计决策

| 决策     | 选择                               | 原因                     |
| ------ | -------------------------------- | ---------------------- |
| 附魔互斥   | 不互斥                              | 允许与锋利等伤害附魔叠加，提高策略自由度   |
| 数据驱动附魔 | 使用 JSON 定义                       | 1.21.4 原生数据驱动方式，无需代码注册 |
| 网络同步   | Fabric Networking API            | 区分 PvP/PvE 可见性，防止信息泄露  |
| 标记存储   | 服务端 ConcurrentHashMap            | 简单高效，服务重启自动清空          |
| 死亡动画   | 依赖 KillLineAnimation Library Mod | 动画系统独立复用，斩杀线注册自定义动画类型  |

## 依赖

| Mod               | 类型      | 说明                           |
| ----------------- | ------- | ---------------------------- |
| KillLineAnimation | Library | 提供死亡动画基础设施、碎片渲染、Mixin 抑制默认动画 |
